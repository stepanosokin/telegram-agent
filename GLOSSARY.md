# Общение с агентами через Telegram

Проект связывает личный чат владельца с рабочими сессиями Codex и OpenCode.

## Язык проекта

**Сессия агента**
Диалог в Codex или OpenCode со своим контекстом и историей. У одного агента может быть несколько сессий.

**Подключённая сессия**
Сессия агента, в которой владелец может из Telegram получать сообщения и отвечать в том же диалоге.

**Привязка сообщения**
Связь сообщения бота в Telegram с конкретной сессией агента и, если в сообщении есть кнопки запроса, с исходным запросом.

**Возобновление сессии**
Продолжение ранее сохранённого диалога с его исходным идентификатором и историей после завершения текущего хода.

**Владелец**
Единственный пользователь Telegram, которому разрешено общаться с сессиями агентов через бота в закреплённом личном чате.

**Запрос выбора**
Вопрос агента, к которому приложены варианты ответа.

**Запрос разрешения**
Просьба агента подтвердить действие, требующее разрешения по правилам Codex или OpenCode.

**Разовое разрешение**
Согласие владельца на конкретное действие из одного запроса разрешения.

**Режим только уведомлений**
Режим, в котором бот доставляет владельцу уведомления, а владелец отвечает агентам на компьютере.

**Получатель обновлений Telegram**
Экземпляр обработчика, через который бот принимает входящие сообщения и нажатия владельца. У бота один активный получатель обновлений.

# Triage labels

Apply the GitHub label that matches the triage role.

| Role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | The maintainer needs to assess the issue. |
| `needs-info` | `needs-info` | More information is needed from the reporter. |
| `ready-for-agent` | `ready-for-agent` | The issue is specified and ready for an agent. |
| `ready-for-human` | `ready-for-human` | A human needs to implement the issue. |
| `wontfix` | `wontfix` | The issue will be closed without implementation. |
